# 🎓 Sistema de Alunos

Sistema desenvolvido como projeto acadêmico para cadastro e localização de alunos por campus.

## 💻 Sobre o projeto

O sistema permite cadastrar alunos em diferentes campi e localizar em qual campus um determinado aluno está cadastrado.

O projeto utiliza uma estrutura de **árvore binária** para organizar e realizar a busca dos alunos.

## 🚀 Funcionalidades

- Cadastro de alunos
- Seleção do campus
- Localização de alunos
- Listagem dos alunos cadastrados
- Organização dos alunos utilizando árvore binária
- Interface web para interação com o sistema

## 🛠️ Tecnologias utilizadas

- Java
- HTML5
- CSS3
- JavaScript
- Estrutura de Dados — Árvore Binária

## 🏫 Campi

O sistema possui cadastro para diferentes campi:

- Anália Franco
- Guarulhos
- Liberdade
- Paulista
- São Miguel
- Santo Amaro
- Villa Lobos
